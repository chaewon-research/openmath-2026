\begin{abstract}
This report documents the unchanged 512-rule certificate evaluated in AutoLab experiment 351d2794. Each rule certifies strict descent after a prescribed sequence of accelerated odd Collatz steps for an entire positive odd dyadic residue class. The original signed official validation report records coverage of 1,000,000 parts per million (ppm), minimum descent of 525,390 ppm, and 512 rules, with \texttt{final=false}. Public offline inspection verifies all rules and covers 3,352 of 3,968 target classes at powers 8--12; the certificate union consists of 1,765 odd residues modulo 4,096. Exact artifact bytes, immutable commit evidence, public checker code, and reproduction instructions accompany the report. This is not a proof of the Collatz conjecture. Competition final submission/acceptance receipt is not yet available, and this GitHub review packet is not evidence of an official final submission.
\end{abstract}

\section{Problem and setup}
For a positive odd integer $n$, define the accelerated Collatz map
\[
 C(n)=\frac{3n+1}{2^{v_2(3n+1)}},
\]
where $v_2(m)$ is the exact exponent of 2 dividing a positive integer $m$.
The organizer's public modular descent task asks for finite exact certificates of strict descent on whole congruence classes; it does not ask for a proof of the full conjecture~\cite{publichill}.
A rule consists of $(k,r,[e_1,\ldots,e_s])$, with odd $0<r<2^k$ and positive integer exponents specifying the exact valuations along $s$ accelerated steps. The public submission schema allows at most 512 rules, $2\leq k\leq32$, $1\leq s\leq24$, and $1\leq e_i\leq32$. The preserved artifact is the sole authoritative rule list, \file{solution.json}.

The local public target universe is
\[
 \mathcal T=\{(p,q):8\leq p\leq12,\ 0<q<2^p,\ q\text{ odd}\},
 \qquad |\mathcal T|=3968.
\]
A target is covered when its entire class is a subclass of a certified rule: $p\geq k$ and $q\equiv r\pmod{2^k}$. This universe is defined mathematically from the public power range, not copied from a private split. Official validation instead uses a held-out weighted target collection; no target instances from that collection are supplied.

\section{Certificate construction and descent statement}
For a rule, set $E_0=0$, $E_i=\sum_{j=1}^i e_j$, and $B_0=0$. Compose the affine maps using
\[
 B_i=3B_{i-1}+2^{E_{i-1}},\qquad A=3^s,\quad B=B_s,\quad D=2^{E_s}.
\]
The checker requires the exact valuation sequence on the least positive representative $r$, the stability condition $k\geq E_s+1$, strict contraction $A<D$, and strict descent at the representative:
\[
 Ar+B<Dr.
\]
For every rule in the preserved artifact and every integer $t\geq0$, the certified statement is
\[
 n=r+2^kt\quad\Longrightarrow\quad C^s(n)=\frac{An+B}{D}<n.
\]
This is the descent statement already supported by the certificate and \file{RESULT.md}; no stronger theorem or formal proof artifact is asserted here.

To explain why the finite checks suffice, before step $i$ the orbit difference from the representative is $3^{i-1}2^{k-E_{i-1}}t$. The step numerator therefore changes by a multiple of $2^{e_i+1}$ because $k\geq E_s+1$. The exact valuation remains $e_i$. Induction gives the affine expression, and
\[
 (D-A)n-B\geq(D-A)r-B>0
\]
proves descent for the entire class. Assumptions are positive integer arithmetic, normalized odd residues, the standard valuation definition, and the exact rule data. No unproved Collatz assumption or probabilistic model is used.

Existing historical code enumerated valuation prefixes, checked candidate rules, and selected dyadic supports within the rule budget. The archived V3/V4 materials describe coverage and contraction tradeoffs. The frozen revision replaces the V4 rule $(8,113,[2])$ with $(5,17,[2])$, retaining 512 rules and broadening that rule's class support. Those files document prior construction, not a newly executed search. Historical optimization claims were not rerun; the staged-debug objective in \file{history/collatz-search/search_v4.py} prevents treating its broad description as an independently verified global optimality result.

The pinned offline replay is CPython 3.14.2 with no third-party dependencies, network, private files or AutoLab credentials.

\begin{verbatim}
cd submission/collatz-modular-descent

python3 check.py --output /tmp/collatz-local-check.json
cmp local-check.json /tmp/collatz-local-check.json

\section{Formalization status and limitations}
\begin{quote}
No Lean formalization was produced for this submission. Verification is provided by the supplied exact checker/certificate pipeline and the signed AutoLab validation report.
\end{quote}
The executable verification relies on the checker, schema loader and Python runtime; it is not a Lean kernel proof. The report does not cover every positive odd integer, establish arrival at 1 for every trajectory, exclude all nontrivial cycles, or exclude divergence. Repeated class descent does not complete an induction without handling the remaining classes. The fixed point 1 is not a strict descent case, and even integers are not directly in the stated odd-class result.

\textbf{This is not a proof of the Collatz conjecture.} No new optimization or official evaluation was run to prepare the review packet or this report. The report is newly written documentation of existing artifacts, not a manuscript from the original experiment. Final/test evaluation, complete original execution-environment reconstruction, formalization and independent literature validation remain unavailable.
